# 无缝循环接缝查找器（Loop Seam Finder）

在浏览器本地分析音频，为循环区间自动搜索平滑接缝点的 Web 工具。
技术栈：React + TypeScript + Web Audio API，**音频不会上传，全部在本地处理**。

## 一键启动（Docker）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**（容器内监听端口 **80**，经 docker-compose 映射到宿主机 **8080**；
如端口被占用，可修改 `docker-compose.yml` 中 `"8080:80"` 左侧的宿主机端口）。

停止：`docker compose down`。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 产物输出到 dist/
npm run preview    # 预览构建产物（http://localhost:4173）
```

## 使用流程

1. **导入音频**：点击或拖入 WAV / MP3 文件，浏览器本地解码并显示波形。
2. **立体声 / 单声道兼容性检查（双声道文件自动执行）**：导入**双声道立体声**后，系统在
   **后台 Worker 线程**按 **100 ms 检查窗、50 ms 步长**逐窗计算：① 左右声道去均值
   Pearson 相关度（−1 ～ 1）；② 等权合并单声道 m =（L + R）/2 相对原立体声的能量损失
   （dB，恒 ≤ 0）。**低于 −50 dBFS 的安静窗不参与风险判定**；连续**损失达到 6 dB**的
   窗口合并为风险区间，列表给出每个区间的起止时间、持续时长、风险窗数、**最差相关度**与
   **最大损失**。点击任意区间即把它**载入波形选区**（旧周期与接缝候选随之清空），
   再用「试听原立体声 / 试听等权单声道」按钮 A/B 切换（循环播放，再点一次停止），
   核对抵消造成的音量塌陷。**单声道（及非双声道）文件显示「不适用」提示**；
   换文件自动清除旧结果，也可点击「重新检查」手动重跑，分析期间页面可继续操作。
3. **框选区间**：在波形上拖拽框选大致的循环区间；橙色边界把手可拖动微调。
4. **发现重复片段（可选）**：点击「发现重复片段」，系统在**后台 Worker 线程**对整段音频
   提取固定步长的多频带能量特征，构建跨时间自相似匹配并沿对角线合并连续命中，
   过滤自匹配、区间重叠与过短段落后列出**最多 5 组重复片段**（两个区间、持续时间
   与相似度），分析期间页面可继续操作。点击任意结果即把**较早区间**载入波形选区
   （旧周期与接缝候选随之清空，可直接进入后续步骤）；音频太短、接近静音或无满足
   条件的命中时给出明确空状态提示，**当前选区不会被改动**。
5. **周期校准（可选）**：点击「分析周期」，系统将整段音频混合为单声道并提取短时能量
   变化包络，在可用音频范围内对**选区长度 1/2～2 倍**的滞后做归一化自相关，
   抑制整数倍/分频重复峰后给出**前 3 个周期候选及置信度**。点击候选即把选区终点
   吸附到该周期，此后接缝搜索切换为**定长约束**：起止点必须等量平移，周期样本数
   保持不变（再次点击已吸附候选或「解除定长约束」可恢复吸附前选区；手动改变选区
   长度也会解除定长）。音频太短、接近静音或无显著峰时不会强制吸附，会提示原因并
   保留原选区。
6. **查找候选接缝**：点击「查找候选接缝」，系统会在两个边界 ±搜索半径 内枚举候选采样点
   （定长模式下起止点同步平移），以「幅值差 + 短窗斜率差」（按信号 RMS 归一化、全声道求和）为代价函数，
   经粗网格 + 逐采样点两级搜索找出**代价最低的 5 个接缝**；
   起止点均相距不足 10 ms 的结果会被去重，避免同一局部极小值占满列表。
   候选按代价升序排列，波形上以绿色编号徽标同步标出（高亮为当前选中）。
7. **点选候选试听**：点击候选列表中的任意一行即循环试听该候选（再点一次停止），
   当前选中项即为导出目标；「试听原区间」可随时 A/B 对比，
   优化区间按设定的交叉淡化时长做等功率淡化。
8. **微调参数**：搜索半径（5–500 ms）与交叉淡化时长（0–500 ms）均可调；
   修改淡化时长会在播放中实时生效；**调整选区或搜索半径会清空候选并禁用导出**，需重新查找。
9. **接缝频谱检查**：选中候选后，面板对循环尾部与头部各取一段检查窗（50–500 ms 可调），
   按重叠 Hann 窗（75% 重叠）做 STFT，把对应时间帧（按与接缝的距离配对）的
   8 个对数频带能量差（dB，头 − 尾）绘成热图；滚轮缩放、拖拽平移、双击复位，
   悬停可查看单点数值。面板汇总最大差值与最差频带；
   检查窗超过循环长度一半时自动夹取并提示；切换候选或交叉淡化时实时重算。
10. **导出**：「下载 JSON」获得选中候选的起止时间、全部候选列表、搜索参数、
    周期校准结果（周期、置信度与定长搜索标记）、重复片段发现结果、
    **立体声/单声道兼容性检查结果（参数、窗统计与风险区间）**与接缝频谱诊断；
    「下载 WAV」导出选中候选的循环音频（16-bit PCM，含 smpl 循环区块）。

| `original` | 用户粗选区间（秒与采样点） |

## 算法说明

- **立体声/单声道兼容性检查**：仅对双声道（2 声道）文件进行，分析在 Web Worker 中执行，
  不阻塞页面。按 100 ms 检查窗、50 ms 步长取**完整窗**（末尾不足一窗的部分忽略）逐窗计算：
  左右声道分别去均值后的 **Pearson 相关度**（某声道零方差时记为 1，即不存在反相抵消）；
  等权单声道 m =（L + R）/2 的窗能量与原立体声平均声道能量 (E_L + E_R)/2 之比，
  取 10·log₁₀ 得**能量损失 dB**（恒 ≤ 0：L = R 时 0 dB，不相关信号约 −3 dB，
  R = −L 完全反相时趋于 −∞，数值上以 −120 dB 为下限）。双声道平均 RMS 电平低于
  −50 dBFS 的窗标记为**安静窗**，不参与风险判定（但仍会切断区间连续性）；
  其余窗中能量损失达到 −6 dB 的为**风险窗**，时间上连续的风险窗合并为一个风险区间，
  区间汇报其中最差（最小）相关度与最大（最负）损失；区间时间覆盖首窗起点到末窗终点。
  音频短于一个检查窗时返回 `too-short`，单声道 / 多声道文件返回 `not-stereo`
  （面板显示不适用），均不改动任何选区。
- **重复片段发现**：整段音频混合为单声道，Hann 窗 STFT（窗长约 46 ms 的 2 的幂），
  提取 40 Hz ~ Nyquist 等比划分的 8 个对数频带能量（dB，动态下限）作为特征；
  帧移固定（默认 15 ms，长音频按比例加大以把总帧数限制在 8000 以内）。
  逐频带减去全曲均值后做 L2 归一化，帧间相似度为余弦相似度；对每个滞后 d
  （相似矩阵的一条对角线）计算 sim(t, t+d)，连续 ≥ 0.9 的命中沿对角线合并
  （允许 ≤ 2 帧的短暂断裂）为一次重复。滞后小于最短段落（0.5 s）的对角线不扫描
  （排除自匹配与必然重叠的区间对），命中段长度超过滞后时夹取为滞后值
  （两区间首尾相接、互不重叠）；候选按相似度降序贪心接受，两个区间起点均相距
  不足 0.15 s 的视为同一重复被去重，最多保留 5 组。静音帧（帧能量低于约
  −80 dBFS）不参与匹配；整段静音、特征帧不足或无可靠命中时返回空状态，
  不改变当前选区。分析在 Web Worker 中执行，不阻塞页面。
- **周期校准**：整段音频混合为单声道，取 20 ms 帧（5 ms 帧移）的短时能量一阶差分
  作为能量变化包络；对每个滞后 τ（选区长度的 1/2～2 倍，限制在可用音频范围内）
  在 [0, N−τ) 上分别去均值做归一化自相关（Pearson 形式，超出计算量预算时按步进抽样），
  局部峰经抛物线插值得到亚帧精度周期；按相关值降序贪心接受候选，
  与已接受候选互为整数倍 / 整数分频（相对容差 3%）的重复峰被抑制，最多保留 3 个；
  置信度即峰值归一化自相关（0～1）。最强峰低于 0.30、音频过短（包络无法覆盖滞后
  范围）或接近静音（帧能量低于约 −80 dBFS）时不给出候选，也不强制吸附。
- **定长接缝搜索**：周期吸附后接缝搜索退化为对起点的一维搜索
  （终点 = 起点 + 周期样本数，起止点等量平移），搜索半径、候选去重与试听流程不变。
- **接缝代价**：`Σ声道 (|x[s] − x[e−1]| / RMS幅值 + w·|前向斜率(s) − 后向斜率(e)| / RMS斜率)`，
  斜率取接缝两侧各 32 个采样点的短窗平均变化率。
- **候选去重**：粗网格命中按代价升序贪心筛选，起止点均相距不足 10 ms 的命中
  视为同一局部极小值被跳过；逐采样点细化后再次去重，保证候选列表覆盖不同的低谷。
- **交叉淡化**：循环尾部 N 个采样点与头部 N 个采样点做等功率（sin/cos）淡化，
  循环体整体前移 N 个采样点，保证回绕处连续无爆音。
- **接缝频谱检查**：对构建后的循环 PCM（与试听 / 导出口径一致）的尾部与头部
  各取检查窗长度片段，Hann 窗 + 75% 重叠做 STFT（FFT 大小为不超过窗长的 2 的幂，
  64–2048），频带按 40 Hz ~ Nyquist 等比划分为 8 个对数频带，多声道按频带能量平均；
  头部第 j 帧与尾部倒数第 j 帧（与接缝等距）求 dB 差。频带能量下限取
  「该帧总能量 −90 dB」与绝对下限（约 −120 dB）的较大者，
  静音 / 远弱频带不会产生 NaN / Infinity 或数值噪声级的虚假差值。
